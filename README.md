## 📌 About the Project

**Farm2Home** is a UI/UX design project focused on creating a simple,
accessible, and user-friendly digital marketplace for farmers in
Gujarat, India. The design aims to make it easier for consumers to
explore farm products and understand how they can buy directly from
farmers.

This repository README documents the design project. It does **not**
describe a coded or deployable application.

## 🎯 Project Goals

-   Create a clear and welcoming farm-to-home marketplace experience.
-   Present farm products in an easy-to-browse layout.
-   Make the interface suitable for users across desktop, mobile, and
    tablet screens.
-   Use a visual direction that feels relevant to Indian and Gujarati
    farmers and customers.
-   Keep navigation and content easy to understand.

## 📱 Responsive Design Screens

The design work is organized by screen size in this order:

1.  **Desktop** --- the main wide-screen layout.
2.  **Mobile** --- a compact layout for phone screens.
3.  **Tablet** --- a layout adapted for medium-sized screens.
